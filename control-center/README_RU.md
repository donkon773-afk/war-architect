# NeroAI — Центр запуска

Локальное мини-приложение для подготовки Arma 3 с NeroAI. Ярлык на рабочем столе:
**NeroAI Control Center**. Панель также доступна по адресу http://127.0.0.1:18775/
(если порт занят, приложение выбирает следующий до 18785). Это отдельное приложение,
а не расширение магазина плагинов Codex.

## Как пользоваться

1. Откройте ярлык и выберите готовый пресет либо сценарий **Warlords / Antistasi Ultimate**.
2. Выберите одну модель или две. В режиме двух моделей первая отвечает за стратегию,
   вторая — за тактические решения. Можно выбрать узел и модель для каждой роли отдельно.
3. Нажмите **Проверить модели**. Список появляется из API выбранного узла;
   перед запуском дополнительно проверяется настоящий ответ выбранной модели.
4. Укажите профиль Arma, ACE и параметры Warlords. **Сохранить пресет** сохраняет
   всё сочетание под своим именем. **Сохранить настройки** сохраняет текущий выбор.
5. Нажмите **Обновить мод и запустить Arma**. Если игра открыта, сохраните прогресс
   и закройте её сами. Приложение не закрывает игру и не запускает второй экземпляр.
6. В игре создайте локальный сервер и выберите указанную миссию. В лобби включите ИИ.
   Параметры приложения становятся значениями по умолчанию; их можно изменить в лобби.
   Antistasi загружается из игры, а настройки кампании и права Зевса задаёт сама кампания.

## Доступные возможности

- Узлы: импортированные MacBook и RTX 3070; дополнительные адреса API можно добавлять.
  Нужен совместимый с OpenAI API сервер, например LM Studio, с доступом по сети.
- Выбор модели из списка узла или по точному идентификатору; температура 0–1.5,
  предел ответа 256–4096 токенов.
- Warlords: Australia, Takistan, Altis, Chernarus. По 10 мест командиров на сторону.
- 26 настроек Warlords: CP и доход, 9/12 подчинённых, быстрое перемещение игроков/ботов,
  время, исходный контроль секторов, сканирование, голосование, арсенал, маркеры,
  усталость, звук, лимит CP, уборка техники, LLM, авиация, сложность и агрессия.
- ACE: включение мода в запуск. Настройки загруженных дополнений доступны в самой игре
  через CBA: **Esc → Настройки → Настройки дополнений → Клиент / Сервер / Миссия**.
- Dev Warlords: отладочная консоль, Зевс для хоста. Права Antistasi не подменяются.
- Запуск обычного клиента через Steam с постоянным профилем; отдельные сервер и HC
  не запускаются. Выбор миссии и начало матча остаются в игре.

Текущий пресет **Australia · Mac · Dev**: одна `openai/gpt-oss-20b` на MacBook,
профиль `donko`, температура 0.9, 900 токенов, ACE, Dev, стартовые 10000 CP,
9 подчинённых плюс командир, быстрое перемещение игроков и ботов, до 5 бортов LLM
на сторону, обычная сложность, сбалансированный стиль. Лимит авиации — разрешённый
максимум, а не обещание немедленного появления пяти самолётов. Покупки требуют CP
и нужного обслуживания сектора. Отряды пополняются покупками, а не бесплатно.

## Что приложение проверяет и хранит

Настройки: `data/profiles.json`; отдельные конфигурации мостов: `data/runtime/`.
Исходные конфигурации Antistasi и Warlords не перезаписываются. Для Warlords
миссии пересобираются, проверяются и устанавливаются вместе с проверенным аддоном.
Предыдущие установленные файлы сохраняются в `../backups/control-center-*`.
Перезапускаются только известные мосты NeroAI этих двух проектов.

Журнал запуска: `logs/last-launch.json`; вывод помощника: `logs/launch-helper.log`;
ошибки: `logs/launch-error.log`; мост: `logs/bridge-*.stdout.log` и `stderr.log`.
Старый файл ошибки может остаться после успешного запуска: смотрите время и состояние панели.
Панель слушает только этот ПК и не публикуется в локальной сети.

Приложение выбирает уже работающий API узла. Оно не устанавливает и не загружает
модель на удалённом Mac/ПК. Вторая LLM здесь принимает тактические решения;
машинное зрение отключено до подключения настоящего источника кадров.

## Редактор и инструкции — 5 октября 2026

Новый пресет: **Australia · Mac · 16 · авиация**. Поле инструкций до 3000 символов применяется к Warlords и сохраняется в пресете. Выбирайте фракции своей нативной стороны и технику через поиск/флажки; приложение добавит моды выбранных классов к базовому набору. До 16 командирских мест на сторону, включая игрока; подчинённые 9/12 задаются отдельно.

Подробная инструкция редактирования, сборки, установки, отката и игровой проверки для другого агента: [AGENT_HANDOFF_RU.md](../docs/AGENT_HANDOFF_RU.md). Новые воздушные задачи реализованы, но требуют следующей игровой проверки.

## Гарнизоны, союзники и консоль — 6 октября 2026

В параметрах миссии задайте независимые максимумы гарнизонов синих, красных и зелёных незахваченных городов: «Штатный», 0, 6, 12, 18, 24, 36, 60. Лимит включает экипажи защитников, но не удаляет атакующие армии. Изменения применять в новой миссии.

Подключение союзных AI-отрядов: выключено / вручную / автоматически. Группа игрока остаётся под его управлением. В настройках LLM союзники используют основную модель либо отдельный узел и модель; текущему одному Mac подходит общий маршрут.

Каталог техники всех установленных модов поддерживает поиск, фильтр и страницы по 60 записей. Выбранные классы включаются в покупки своей нативной стороны; поставщики выбранной техники добавляются при запуске. До 512 классов на сторону, без автоматической загрузки всего Workshop.

Разверните журнал работы LLM в приложении либо нажмите кнопку открытия консоли. Отдельный файл на рабочем столе `NeroAI-LLM-console.cmd` открывает просмотр моста и игрового журнала; закрытие окна не останавливает мод. Новые подробные поля входа/итогового ответа появятся после следующего запуска моста.

Zeus: зарегистрированы объекты сценария и новые объекты; навыки и пилоны редактируются через установленный Zeus Enhanced, если самолёт поддерживает динамические пилоны. Новые лимиты и редактирование требуют следующей проверки в игре. Подробности для агента — раздел 16 [инструкции](../docs/AGENT_HANDOFF_RU.md).
