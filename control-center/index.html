Покупка пехоты за CP

Для каждой стороны выберите автоматический состав фракции или свой список бойцов из модов. Цены и список общие для игрока и ботов этой стороны. Зелёные покупки используются в трёхстороннем режиме редактора карты.

Цена: 60–50000 CP. Свой список может быть пустым, максимум 256 типов. Автоматический список — до 12 типов; фракции задаются во вкладке «Стороны и техника»; армии сохраняются вместе с открытым сценарием. Сохраните настройки или пресет и запустите новую миссию для применения.

Параметры Warlords перед игрой

Станут значениями по умолчанию в лобби выбранной миссии. Их можно изменить в «Параметрах» перед стартом.

Инструкции перед игрой

Сохраняются в пресете. Модель получает их при каждом решении; правила покупки, безопасности и прямые приказы игрока продолжают действовать.

Журнал LLM и исполнения в Arma

Вход игры → выбранная модель → финальный JSON → проверенные команды → результат из RPT. Отправка команды ещё не означает её выполнение. Старые строки отмечены временем.

Настройки ACE и остальных загруженных модов: Esc → Настройки → Настройки дополнений, вкладки «Клиент / Сервер / Миссия».
Warlords: удерживайте клавишу инвентаря (обычно I) для покупок и быстрого перемещения. Зевс: обычно Y. Консоль: Esc.

Базы и сектора — на карте. Все параметры и армии — в разделе «Сценарий». Ctrl+S сохраняет всё вместе.
