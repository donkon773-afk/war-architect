NeroAI Control Center — демо-копия для просмотра
================================================

Как открыть
-----------
1. Распакуйте архив целиком (правой кнопкой → «Извлечь всё…»).
   Открывать прямо из архива нельзя — браузер не увидит соседние файлы.
2. Двойной щелчок по файлу «NeroAI Control Center.html».
   Откроется в браузере (Chrome, Edge, Яндекс, Firefox). Интернет и установка
   не нужны.

Что это
-------
Центр запуска NeroAI — панель, через которую готовится Arma 3 с модом NeroAI:
сценарий Warlords или Antistasi, LLM-командиры (одна или две модели), фракции и
техника сторон, покупка пехоты, правила и параметры миссии, инструкции для ИИ,
редактор карт (базы, секторы, спавны) и пресеты.

Это снимок настоящей панели от {{DATE}} с теми же экранами и пресетами.
Можно переключать вкладки, менять настройки, сохранять пресеты, открывать
редактор карт и расставлять точки. Изменения живут, пока открыта вкладка
браузера, и пропадают после её закрытия.

Что отключено в копии
---------------------
- запуск Arma 3, сборка мода и миссий;
- проверка моделей идёт по сохранённому списку, а не по живому API узла;
- журналы моста и игры;
- сборка спутниковых карт из файлов игры и загрузка своих изображений.

{{MAPS}}

Адреса LLM-узлов и имя профиля Arma заменены на условные. Ключей API в копии нет.
