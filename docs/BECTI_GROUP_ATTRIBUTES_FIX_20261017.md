# BECTI: кнопка «Играть» остаётся в списке миссий

17.10.2026. Пользователь подтвердил, что отказ сохраняется на сборке `6ad089085ce8`, а стандартная миссия из того же меню запускается. Предыдущее добавление сетевых метаданных не устранило отказ.

## Воспроизведённая причина

Сборщик BECTI не создавал `class Attributes {};` непосредственно внутри сущностей `dataType="Group"`. Атрибуты отдельных бойцов присутствовали, но не заменяют атрибуты группы. Движок пропускает такие группы при чтении игровых ролей, и миссия с ними не переходит к запуску. В обычном клиентском RPT ошибка SQF не появляется, потому что SQF ещё не запускается.

Изолированная проверка Arma 3 Server 2.22.154089 на localhost, отдельном порту 24302 и временном профиле:

| Проверка | Результат |
| --- | --- |
| Исходный SQM BECTI с заменой RHS-бойцов на доступный стандартный класс и минимальным description.ext | `Starting mission` и `[WA PROBE] Init reached` |
| Созданный редактором SQM с минимальным description.ext | Запуск не достигнут |
| Замена версии SQM 54 на 53 | Запуск не достигнут |
| Добавление исходных метаданных и Intel | Запуск не достигнут |
| Только один созданный редактором игровой слот | Запуск не достигнут |
| Тот же слот, единственное изменение — атрибуты группы | `Starting mission` в 04:23:22; `Init reached` в 04:23:30 |
| Все созданные редактором группы с исправлением, полный BECTI description.ext и функции | `Starting mission` в 04:25:36; `Playable=40 Groups=42` в 04:25:44 |

Последняя проверка использовала Altis, замену статических CUP-бойцов стандартными и диагностический init вместо полной экономики. Это подтверждает чтение всех 40 ролей, 42 групп и полного description.ext самим движком. Она не доказывает работоспособность экономики, покупок, поведения ИИ или клиентского интерфейса в Australia.

В диагностической копии для Altis нужен `A3_Map_Altis` в addons, а не имя мира `Altis`. Первоначальная копия с ошибочной зависимостью отдельно сохранена и не считается успешным тестом. Предупреждение о `a3_characters_f` возникает также перед успешной исходной миссией и не является установленной причиной этого отказа. SQF-VM не понимает часть нативных локализованных конфигураций; его отказ разбора также не считается ошибкой Arma.
