## Применение

Последняя проверка конструктора: PID 18376 на 18792, busy=false; это прежний процесс, запущенный до исправлений. Он держит серверные модули в памяти. Обновление страницы подгружает новый JS интерфейса, но для новых правил сохранения требуется перезапуск служб центра. Ранее автоматическая проверка отклонила остановку/перезапуск с `blocked by policy`; обхода и новой попытки в этой задаче не было. Пользователю нужно вручную закрыть старые node.exe центра и конструктора (последние PID 19732/18376), открыть обычный ярлык и обновить страницу. Перед обновлением сохранить несохранённый черновик.

Продолжение: после ручного перезапуска проверить сохранение и повторное открытие большого пользовательского сетапа через обычный интерфейс. Для применения нового состава в Arma пересобрать соответствующую миссию; не менять значения лимитов живых юнитов без отдельной настройки пользователя, не заменять установленный мод ради снятия ограничений редактора.

Обновление активации: после нового прямого указания пользователя закрыть старое меню без сохранения черновика штатная остановка и запуск через control-center/start.ps1 выполнены успешно. Прежние PID 19732/18376 заменены на 12912 (центр, 18775) и 19060 (конструктор, 18792). /health отвечает, главная страница возвращает HTTP 200. Открыто новое окно штатным стартовым скриптом; запрос вкладки Codex браузера поставлен приложением в очередь. Серверные модули теперь загружены после исправлений, ручное завершение процессов больше не требуется.
