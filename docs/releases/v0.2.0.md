# v0.2.0 — Sector Command BECTI and combined-arms AI

[English](#english) · [Українська](#ukrainian) · [Русский](#russian)

<a id="english"></a>

## English

This prerelease adds the War Architect BECTI adapter and a server-tested first iteration of coordinated attacks. It does not establish complete combat or weapon validation.

### Changes and fixes

- Editable BECTI bases, towns, armies and native parameters, retaining native economics and factories.
- Mod-aware shop with firearms, launchers, ammunition, radar and air defense, search, cart, order feedback, and crewed/empty vehicle selection.
- Explicit commander action, command hub and host/admin Zeus assignment.
- Automatic attack preparation, physical roster/crew checks, staging, support, withdrawal and target reconsideration; explicit player commands retain priority.
- Bounded road routing, mechanized dismounts, separate aviation roles, initial climb, return tasks and conditional field repair.
- Fixes for mission entry/client initialization, player/HQ placement, first-life AI registration, purchase creation isolation, stalled factory queues, map order types and Zeus patch filtering.
- Duplicate vehicle requests and excess passenger recruitment are constrained by actual queue/vehicle state and capacity. A duplicate vehicle purchase is rejected without charging funds.
- An engine test exposed an operator-precedence error in objective scoring; it was corrected and retested.
- Publication now includes the required Zeus function index; the archival test no longer depends on an old local PBO.
- Verified addon artifacts are reused without overwriting files held by the running game. Frontline/Supply cart and transport changes are included, with separate gameplay acceptance still pending.

### Validation and remaining work

All 46 selected Node tests pass in the publication checkout, including ten targeted BECTI/artifact tests. Generated mission validation parses 87 SQF files and checks 35 functions, 92 parameters and 10 towns. A modded Arma dedicated-server probe passes 25 assertions, including real queued CGR creation with its required crew, exact native-account debit, duplicate rejection and manual-order preservation. The final run has no SQF expression errors; existing mod warnings are not a blanket compatibility pass.

The repair function call was checked against the installed ACE implementation; a complete ACE field repair in combat is still unverified.

Full autonomous base construction, road traversal, combat capture, actual air strikes/interception, ACE field repair and long-session stability remain unverified. Physical BECTI airborne delivery and specialized artillery tasks remain incomplete. No Kh-47/Patriot interception series was run; this release does not substantiate an interception percentage.

Run `npm run prepare:becti` before first BECTI use to fetch the pinned upstream. Arma, terrain and selected mods are separate requirements. Install SQF-VM separately or set `NEROAI_SQFVM` for parser tests. `coordinatedAI` enables the experimental doctrine for automatic capture orders. The release distributes project sources, not game/mod binaries or personal runtime logs.

BECTI upstream: [Kiyogitpy/becti_altis_1355.Altis](https://github.com/Kiyogitpy/becti_altis_1355.Altis), commit `2a883f7ab7f827eea1f7e060b05bf19f4bb96959`; authors Benny, Zerty, HTom, Yoshi_E and Kiyogitpy. BECTI-derived missions retain CC BY-NC-SA 4.0 attribution and terms.

## Українська

Це попереднє оновлення: адаптація BECTI до War Architect і перша ітерація спільних атак, перевірена серверними випробуваннями. Воно не означає завершеної перевірки всіх видів озброєння та бойових сценаріїв.

### Що змінилося

- BECTI додано до редактора й бібліотеки сценаріїв: бази, міста, армії, модифіковане спорядження та штатні параметри BECTI. Економіку й заводи BECTI збережено.
- Магазин отримує вибрані модифіковані класи, стрілецьку зброю, ракетні установки, боєприпаси, РЛС і ППО. Додано пошук, кошик, підтвердження результату та вибір техніки з екіпажем або порожньої.
- Додано явну дію отримання командування, центр керування та призначення Zeus для хоста/адміністратора.
- Автоматичне захоплення отримало підготовку групи, збір, підтримку, відхід і зміну небезпечної цілі. Готовність перевіряє фактичний склад та екіпаж. Ручні накази мають пріоритет.
- Техніка отримує обмежений пошук дорожнього маршруту; механізована піхота спішується перед містом. Авіацію розділено за ролями, з початковим набором висоти та завданнями повернення. Польовий ремонт потребує реальних засобів ремонту й безпечної обстановки.
- Включено зміни кошика й посадки/перекидання в кампанії «Фронт і постачання»; вони потребують окремої перевірки в грі.

### Проблеми та виправлення

- Вхід у місію зупинявся на списку місій/очікуванні сервера: перероблено згенеровану структуру слотів, атрибути груп та ініціалізацію клієнта.
- Гравець з’являвся в морі, штаб міг опинитися під землею: виправлено розміщення гравця, баз і відновлення висоти штабу. Службову зону відокремлено від ігрової бази.
- Модифіковані покупки були відсутні або зависали: додано власний каталог, ізоляцію старого коду створення, перевірку результату та відновлення заводської черги.
- Групи під час першої появи реєструвалися некоректно: реєстрація виконується без примусової загибелі командира й заміни групи.
- Помилки карти й каталогу Zeus: відображення безпечніше обробляє накази різних типів, каталог використовує наявні CfgPatches із коректним масивом units.
- Повторні закупівлі техніки й зайві пасажири: активна черга блокує повторну заявку; набір піхоти враховує місткість транспорту. Повторне замовлення вже наявної машини не списує гроші.
- Серверний тест виявив помилку пріоритету операторів під час вибору сектора: вираз відстані виправлено, повторний запуск пройшов без цієї помилки.
- Виправлено склад публікації індексу функцій Zeus; тест архівації більше не залежить від старого локального PBO.
- Збирання доповнень повторно використовує перевірений PBO й не намагається перезаписати файл, зайнятий грою.

### Що перевірено

- 46 тестів Node у публікаційній копії, включно з 10 цільовими тестами BECTI/збірки; перевірка 87 SQF-файлів, 35 функцій, 92 параметрів і 10 точок згенерованої місії.
- 25 перевірок на виділеному сервері Arma з локальною модовою збіркою: готовність піхоти/екіпажу, рішення щодо підтримки/відходу, скасування автономії ручним наказом, справжня заводська купівля CGR з екіпажем, точне списання грошей і відхилення повторного замовлення.
- Підсумок серверного тесту: `failures=[]`, помилок виконання SQF не виявлено. Це не твердження про відсутність попереджень або конфліктів у всіх завантажених модах.
- Виклик функції ремонту звірено зі встановленим ACE; повноцінний ремонт із ACE в бою поки не перевірено.

### Обмеження та підготовка

Повний цикл будівництва бази, пересування дорогами й захоплення, реальні повітряні удари/перехоплення, польовий ремонт і тривала стабільність потребують перевірки в грі. Фізичний десант BECTI та спеціальні завдання артилерії не завершено. Серію випробувань Х-47 проти Patriot не проводили: цей реліз не підтверджує відсоток перехоплень.

Автономна логіка вмикається через DevMode `coordinatedAI` й автоматичне захоплення. Перед першим використанням BECTI виконайте `npm run prepare:becti`: завантажується закріплена версія upstream. Потрібні власна копія Arma, карта й вибрані моди. SQF-VM встановлюється окремо; шлях можна вказати через `NEROAI_SQFVM`. Вихідний код доступний у релізі; сторонні моди, ігрові бінарні файли й особисті журнали не поширюються.

BECTI upstream: [Kiyogitpy/becti_altis_1355.Altis](https://github.com/Kiyogitpy/becti_altis_1355.Altis), коміт `2a883f7ab7f827eea1f7e060b05bf19f4bb96959`; автори Benny, Zerty, HTom, Yoshi_E та Kiyogitpy. Похідні місії BECTI зберігають зазначення авторства й умови CC BY-NC-SA 4.0.

## Русский

Это предварительное обновление: адаптация BECTI под War Architect и первая проверенная серверными испытаниями итерация совместных атак. Оно не означает завершённую проверку всех видов вооружения и боевых сценариев.

### Что изменилось

- BECTI добавлен в редактор и библиотеку сценариев: базы, города, армии, модифицированное снаряжение и штатные параметры BECTI. Экономика и заводы BECTI сохранены.
- Магазин получает выбранные модифицированные классы, стрелковое оружие, ракетные установки, боеприпасы, РЛС и ПВО. Добавлены поиск, корзина, подтверждение результата и выбор техники с экипажем либо пустой.
- Добавлены явное действие получения командования, центр управления и назначение Zeus для хоста/администратора.
- Автоматический захват получил подготовку группы, сбор, поддержку, отход и смену опасной цели. Готовность проверяет фактический состав и экипаж. Ручные приказы имеют приоритет.
- Техника получает ограниченный поиск дорожного маршрута; механизированная пехота высаживается перед городом. Авиация разделена по ролям, с начальным набором высоты и задачами возврата. Полевой ремонт требует реальных средств ремонта и безопасной обстановки.
- Включены изменения корзины и посадки/переброски в кампании «Фронт и снабжение»; они требуют отдельной игровой приёмки.

### Проблемы и исправления

- Вход в миссию останавливался на списке миссий/ожидании сервера: переработаны сгенерированная структура слотов, атрибуты групп и инициализация клиента.
- Игрок появлялся в море, штаб мог находиться под землёй: исправлены размещение игрока, баз и восстановление высоты штаба. Служебная зона отделена от игровой базы.
- Модифицированные покупки отсутствовали либо зависали: добавлены собственный каталог, изоляция старого кода создания, проверка результата и восстановление заводской очереди.
- Группы первого появления не регистрировались корректно: регистрация выполняется без принудительной гибели командира и замены группы.
- Ошибки карты и каталога Zeus: отображение безопаснее обрабатывает приказы разных типов, каталог использует существующие CfgPatches с корректным массивом units.
- Повторные закупки техники и лишние пассажиры: активная очередь блокирует повторную заявку; набор пехоты учитывает вместимость транспорта. Повторный заказ уже имеющейся машины не списывает деньги.
- Серверный тест выявил ошибку приоритета операторов при выборе сектора: выражение расстояния исправлено, повторный запуск прошёл без этой ошибки.
- Исправлена публикационная комплектация индекса функций Zeus; тест архивации больше не зависит от старого локального PBO.
- Сборка дополнений повторно использует проверенный PBO и не пытается перезаписать файл, занятый игрой.

### Что проверено

- 46 тестов Node в публикационной копии, включая 10 целевых BECTI/сборки; проверка 87 SQF-файлов, 35 функций, 92 параметров и 10 точек сгенерированной миссии.
- 25 проверок в выделенном сервере Arma с локальной модовой сборкой: готовность пехоты/экипажа, решения о поддержке/отходе, отмена автономии ручным приказом, реальная заводская покупка CGR с экипажем, точное списание денег и отказ повторного заказа.
- Итог серверного теста: `failures=[]`, ошибок выполнения SQF не обнаружено. Это не утверждение об отсутствии предупреждений или конфликтов во всех загруженных модах.
- Вызов функции ремонта сверён с установленным ACE; полноценный ремонт с ACE в бою пока не проверен.

### Ограничения и подготовка

Полный цикл строительства базы, движения по дорогам и захвата, реальные воздушные удары/перехваты, полевой ремонт и длительная стабильность требуют игровой проверки. Физический десант BECTI и специальные задачи артиллерии не завершены. Серия испытаний Х-47 против Patriot не проводилась: процент перехвата этим релизом не подтверждён.

Автономная логика включается через DevMode `coordinatedAI` и автоматический захват. Перед первым использованием BECTI выполните `npm run prepare:becti`: скачивается закреплённая версия upstream. Нужны собственная установка Arma, карта и выбранные моды. SQF-VM устанавливается отдельно; путь можно указать через `NEROAI_SQFVM`. Источники доступны в релизе; сторонние моды, игровые бинарники и личные журналы не распространяются.
