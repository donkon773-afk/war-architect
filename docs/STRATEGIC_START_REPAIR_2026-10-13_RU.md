## Причины отказов и исправления

1. Помощник запуска отвергал локальный `@NeroAI_Strategic`, находящийся за пределами каталога Arma. Теперь разрешён только его точный проектный путь с обязательным существующим `addons/NeroStrategic.pbo`. Произвольные внешние пути, похожие префиксы и разделители по-прежнему отклоняются. PowerShell-файл записан в UTF‑8 с BOM; ошибки с русским текстом читаются в PS5.1 и PS7.
2. Необязательный Pinned Down ссылался на отсутствующий Workshop-каталог. Он пропускается в текущем запуске с предупреждением; сохранённый выбор не стирается. Отсутствующие обязательные моды продолжают блокировать сборку. Установленные Workshop-файлы не исправлялись и не перезаписывались.
3. `Undefined base class 'Cruise'` происходила при загрузке NeroStrategic. В конфигурации объявлен внешний вложенный режим `Cruise` с фактическим родителем `MissileLauncher` для `weapon_VLSBase`. Новый `tools/verify-strategic-addon.js` проверяет упакованную конфигурацию относительно установленного FP‑5 перед сборкой миссии. Соответствие внешних вложенных классов описано в [документации BI по наследованию](https://community.bistudio.com/wiki/Class_Inheritence).
4. Даже работающая Arma могла сопровождаться ошибкой помощника: у защищённого процесса CIM возвращал пустую строку аргументов. Проверка больше не обращается к пустому значению; при скрытых аргументах нужны свежий RPT с уникальным запрошенным файлом параметров, правильный исполняемый файл и время нового процесса. Старый или чужой журнал не считается подтверждением. Ожидание игры увеличено до 90 с, внешнего помощника — до 95 с.
5. Длинная строка модов через Steam теряла часть имён; первоначальный файл параметров с абсолютными путями также обрезался. В неудачном RPT 16:45:58 отсутствовал CBA и возникало `Include file x\cba\addons\main\script_macros_common.hpp not found`, хотя заголовок физически присутствовал в PBO. Теперь моды внутри каталога игры записываются относительными путями, локальный аддон — абсолютным. Итоговый файл содержит 3131 байт, все 104 пути реально присутствуют в таблице загруженных модов свежего RPT. Ограничение 4000 байт блокирует чрезмерный список заранее. Файл параметров и относительные пути поддержаны [документацией BI](https://community.bistudio.com/wiki/Startup_Parameters_Config_File) и [параметрами Arma 3](https://community.bistudio.com/wiki?title=Arma_3_Startup_Parameters). Порог проверяется нами; общий предел движка по одному наблюдению не установлен.
6. Инициализация кампании останавливалась при вычислении радиуса аэродрома: выражение с `distance2D` и `+150` применяло сложение к массиву. Расчёт вынесен в чистую `campaignAirfieldRadius`: расстояние по двум координатам, запас 150 м, исходный радиус 750 м, предел 5000 м, обработка пустой/неполной геометрии. В свежем RPT появились `STRATEGIC AIRFIELDS` и полный `CAMPAIGN READY`.
