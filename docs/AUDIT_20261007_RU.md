## 08.10 — ИИ-моды и шаблоны поведения LAMBS как инструменты LLM

- В сборке Warlords не было ни одного ИИ-мода. На диске: LAMBS Danger.fsm 2.6.2 (GitHub nk3nny/LambsDanger, выпуск 18.07.2026, GPL-2.0), LAMBS Suppression, Battle AI v0.92 (автор «YourName», закрытый PBO — не брать), Vision Guard AI/Suppress (эффекты для игрока), Pinned Down: Steel Rain (автономная артиллерия/CAS; есть `spawnVirtualWing` — проверить, не обходит ли экономику). - Решение: LAMBS подключается отдельным модом (`tools/warlords-launch.json`), код не копируется (GPL). LLM выбирает шаблон в поле `support`: ASSAULT CQB|RUSH, HOLD GARRISON|DEFEND, RECON HUNT|CREEP; неизвестный шаблон → обычный приказ (`bridge/protocol.js`), меню в схеме ответа и в обеих копиях промпта.
- `fn_tacticOrder.sqf`: проверка уместности (CQB/GARRISON без ≥2 зданий в 120 м → RUSH/DEFEND), марш по дорогам при >350 м, наблюдатель: у цели (<350 м) или при контакте (враг ≤400 м за 20 с) — высадка пеших для CQB/GARRISON/DEFEND/CREEP, затем задача LAMBS (охота/рывок/скрытность с `onlyPlayers=false`). Без LAMBS — обычный приказ.
- `fn_tacticStop.sqf`: циклы LAMBS (hunt/rush/creep) живут до гибели группы и мягкий `taskReset` их не останавливает → поток задачи и наблюдатель завершаются `terminate`, затем мягкий сброс `[_group,true,false]` (та же группа). Вызывается при любом новом приказе (`executeMacro`, перед увеличением `NeroWL_routeEpoch`).
- `fn_vehicleRoute.sqf`: на дорожном марше `lambs_danger_disableGroupAI=true` (LAMBS не ломает колонны и не высаживает экипажи), в контакте и после маршрута — снова включён.
- Пока шаблон в фазе EXEC: `fn_autoRequisition` не уводит отряд к машине и не покупает; `fn_tacticalAutonomy` не планирует по расписанию 240 с (`NeroAI_tacticReplanSeconds`), события (потери, контакт, застревание) — сразу. В снимке группы последнее поле `[шаблон, MARCH|EXEC, секунды]`.
- Живая проба 3060 (6 планов, радиотишина): модель шаблон не выбрала ни разу, ни до, ни после правки строки формата. Поэтому для автономных приказов без шаблона: штурм точки с ≥6 зданиями в 150 м → CQB, HOLD → GARRISON (без зданий → DEFEND); приказы игрока буквальны (`NeroAI_tacticDefaults`).
