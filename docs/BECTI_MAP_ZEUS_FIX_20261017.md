## Изменения

В карте приказов `_order` сохраняет числовой код группы, а `_waOrderLabel`
содержит только отображаемую подпись. Таблица получает код через `lnbSetValue`
и подпись через `lnbAddRow`; штатное обновление списка сравнивает числовые коды.
Отсутствующее или некорректное значение первоначального приказа заменяется -1.

Для BECTI используется отдельный `zeus-prepare.sqf`, не меняющий общий Zeus
других режимов. До инициализации создаётся список реальных записей CfgPatches,
содержащих массив `units`. Несуществующие старые имена из `activatedAddons`
и `configSourceAddonList` не передаются в каталог куратора. Фильтр применяется
как при создании Zeus, так и в штатном callback добавления новых объектов BECTI.
Модуль получает явный список после инициализации BI/ACE вместо режима Addons=3.
Проверка прав хоста/администратора сохранена.

Это исправляет источник запросов отсутствующих записей, а не сами повреждённые
текстуры/значки сторонних модов. Полное устранение задержек открытия Zeus с
большим каталогом требует клиентской проверки; десятисекундный тайм-аут в старом
RPT сам по себе не устанавливает конкретную причину задержки.
