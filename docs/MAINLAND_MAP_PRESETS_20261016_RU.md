# Компактные пресеты карт — 16 октября 2026

Добавлены 22 редактируемых пресета, по одному для каждой установленной карты. Название в панели: «Название карты · сухопутный фронт». Пять прежних пресетов сохранены; текущая расстановка, выбранная карта, армии и несохранённое состояние открытой страницы не изменялись. Новые пресеты не применены автоматически.

Все пресеты рассчитаны на обычный двухсторонний Warlords: две базы WEST/EAST, нейтральные гарнизоны GUER по 4 пехотинца без гарнизонной техники. Небольшие карты Stratis, Bastek, Lybor (лето/зима), Walzton получили 5 секторов; остальные — 7. Стартовые CP 6000, доход 100, лимиты 160 NPC/24 машины. Фракции основных сторон берутся из выбранной конфигурации запуска; карта не навязывает отдельную армию.

Карты: Altis, Stratis, Archie Summer/Winter, Australia, Bastek, Chernarus, Enoch, Farabad, Fjord, Isla Pera, Lybor Summer/Winter, Malden, Posadkovo, Sanagasta, Takistan, Tanoa, Uzbin, Vereskovo, Virolahti, Walzton.

Расстановка использует существующую маску основного массива суши из WRP установленной карты, сетку 512×512 и векторные дороги. Для новых планировок выбирается связная внутренняя область после исключения узких прибрежных полос. Между базами ищется непрерывный путь по суше, а секторы распределяются вдоль него с предпочтением точек возле дорог. Проверены центр и 16 точек окружности каждой базы (150 м) и сектора (100 м); все находятся на основном массиве суши. На островных картах это означает главный остров, а не запрет островной карты целиком.

Проверки: 22/22 пресета проходят строгую схему сценария; 22/22 имеют две базы и 5 либо 7 секторов; все точки проходят проверку основного массива суши с радиусом. Выполнена визуальная проверка общей схемы поверх спутниковых обзоров. Это проверка планировок по статическим данным, не игровой тест навигации: локальные мосты, скалы, здания и проходимость склонов требуют проверки в Arma.

Использование: открой редактор нужной карты и выбери «Название карты · сухопутный фронт». «Открыть» загружает расстановку для правки; «Использовать в игре» применяет её для запуска. При наличии несохранённых правок сначала сохрани текущую работу; полное обновление страницы для создания пресетов не выполнялось.

Файлы: `control-center/data/map-presets/*.json`. Генератор: `tools/create-mainland-map-presets.js` (повторный запуск не перезаписывает одноимённые пресеты). Проверки и координаты: `dist/mainland-presets-20261016/validation.json`, `layouts.json`. Визуальный обзор: `dist/mainland-presets-20261016/contact-sheet.jpg`.
