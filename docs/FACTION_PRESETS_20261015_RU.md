# Библиотека пресетов фракций NeroAI

Проверка: 15.10.2026. Подготовлено 99 новых сетапов для 67 доступных фракций. С учётом шести прежних сетапов в библиотеке 105 записей. Основание — чтение 1801 установленного config.bin; ошибок чтения и отсутствующих классов исходного каталога не обнаружено. Это статическая проверка файлов, не запуск всех классов в движке.

## Как пользоваться

Открыть http://127.0.0.1:18775/setups → найти название → изменить список техники, пехоты и цены пехоты → «Сохранить сетап» либо «Сделать копию». Применение к стороне выполняется в центре запуска или редакторе карты. Текущая армия автоматически не заменялась.

Пресет хранит явный список классов пехоты. Вооружение и форма берутся из штатных наборов этих классов. Для изменения вооружения через существующий редактор выбирается другой класс бойца; отдельного редактора произвольных оружейных наборов эта работа не добавляет.

## Смысл каноничности

Базовые записи — каталоги собственной фракции установленного мода. Они включают доступную ей технику и вооружение, но не объявлены штатным составом реальной армии на конкретный год. Для вымышленных фракций используется канон Arma. Авиационные и вспомогательные ветви не дополнены выдуманной линейной пехотой или чужими танками.

Специальные национальные сборки и приданные силы отмечены в metadata пакета. M1128 не назван штатной машиной SOCOM: это сценарный вариант спецназа с армейской поддержкой. Британский Harrier выбран в варианте GR9, а F-35B вынесен в другой вариант. Chieftain отсутствует в проверенном каталоге.

Лесные, пустынные и зимние варианты создаются по существующим классам/форме. Если отдельной окраски нет, она не выдумывается. Общие вертолёты и самолёты сохраняют свои штатные окраски. У мобильного MARSOC форма M81 одинакова в обоих вариантах; меняется окраска техники.

## Мобильный пресет США

Пехота: 19 классов MARSOC RHS, включая командира, стрелков, гранатомётчика, сапёра, механика, медика SARC, JTAC/JFO, марксмана и снайперов. При создании миссии командир выбирается из явно выбранной пехоты.

Ключевые машины: Stryker M1128 MGS с 105-мм пушкой, M1134 с TOW, M1126 с M2/Mk19, разведывательный M1127, инженерный M1132, медицинский M1133 и миномётный M1129. Дополнительно — американские лёгкие машины/обеспечение и Little Bird. Гусеничная техника исключена по simulation/наследованию конфигов, а не только по названию или категории TANK.

Основное специализированное средство против танков — M1134; M1128 обеспечивает прямую огневую поддержку. MGS относится к исторической эпохе до объявленного вывода системы к FY2022, а не к строгому штату на 2026 год. [Источник армии США](https://www.army.mil/article/246274/army_announces_divestiture_of_the_stryker_mobile_gun_system).

Старый пользовательский «CCO US» сохранён. Новые варианты «США · SOCOM + Stryker MGS · лес/пустыня» добавлены отдельно.

## Файлы и повторная генерация

- `control-center/data/side-setups/*.json` — редактируемые сетапы, которые читает действующая панель.
- `control-center/data/faction-presets/builtin.json` — исходный пакет, ограничения, происхождение и список оружия каждого пресета.
- `control-center/data/faction-presets/infantry-equipment.json` — штатные оружие, магазины, форма и снаряжение классов пехоты из установленных конфигов. Это справочник, а не отдельный исполняемый override снаряжения.
- `dist/faction-preset-config.json` — проверка классов, simulation и наследования; дерево данных для генератора.
- `tools/faction-preset-config.js` — повторное чтение конфигов.
- `tools/build-faction-presets.js` — сборка пакета; `--install` добавляет только отсутствующие ID и сохраняет существующие правки.
- `backups/faction-presets-20261015` — прежний warlords-editor.js и шесть старых сетапов.

Команды из корня проекта:

```powershell
node tools/faction-preset-config.js
node tools/build-faction-presets.js --install
node --test tests/faction-presets.test.js tests/side-setups.test.js tests/warlords-editor.test.js
```

Повторная установка не заменяет ранее созданные записи, даже если пользователь переименовал их или изменил состав. Чтобы взять новый базовый вариант после изменения генератора, нужно создать новую копию осознанно; удалённые пользователем заводские ID повторная установка может восстановить.

Текущая панель уже читает новые JSON.
