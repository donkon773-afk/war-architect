## Причина

`ErrorMessage: File NeroMissileProfiles\config.cpp, line 26: /CfgAmmo.rhs_ammo_kh55sh: Undefined base class 'rhs_ammo_kh55sm'`

Затем `Application terminated intentionally`, исключение `0000DEAD`. Ошибка возникает до загрузки мира и миссии. Параметры запуска содержат мод @NeroAI_Missiles_395c0b64af5e, созданный нашим генератором. Патч функций покупки Warlords к этому моменту не исполнялся.

Генератор перечислял переопределения в порядке профилей. Профиль Х-555 включал rhs_ammo_kh55sh, наследующий rhs_ammo_kh55sm; профиль rhs_ammo_kh55sm шёл позже. При этом базовые классы, которые сами переопределяются, исключались из списка предварительных объявлений. Arma не смогла разрешить наследование. Наш структурный парсер проверял синтаксис/дубликаты, но не такой порядок зависимостей. Это дефект нашего генератора, не установленный факт конфликта ACE или аппаратной неисправности.

После разрешения на подключение следует пересобрать выбранную операцию с новым модулем и обновлённой ссылкой на него; действующий процесс центра может держать старый генератор в памяти, поэтому требуется проверить актуальность его кода при пересборке. Не подменять содержимое старого каталога с хешем новым конфигом. Новый запуск Arma должен пройти загрузку модов, вход в меню и загрузку миссии без Undefined base class; лишь после этого проверять покупки и ракеты в движке. Эти проверки в игре пока не выполнены.
