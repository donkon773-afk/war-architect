# Unified mission library and field-console theme

The old launch profile list showed only profiles from profiles.json. Map scenarios and operation saves were separate libraries behind the map and operations editors. They had not been deleted. The new default Missions page indexes all three stores without copying, modifying or deduplicating their content. At implementation time the local libraries contained 27 map scenarios, 24 operations, and 6 launch profiles.

`control-center/scenario-library.js` returns only display metadata and the original ids; launch models, endpoints and credentials are excluded. `/api/scenario-library` uses the existing session/origin protection. The UI in `library-workspace.js` renders data as text and provides mode filters and name/map search. Each card opens its original editor. Operations use their existing `?id=` loading contract for airBattle, assaultDefense or frontlineCampaign. Warlords presets open in the integrated map editor; useDesign, map and army follow the opened preset. Opening a mission never installs a package or launches Arma.

Before replacing an operation iframe, the parent asks that exact window for dirty/busy state through postMessage. The reply is checked against the frame window, expected origin and request id. Busy editors cannot be replaced, and declining discard leaves the previous operation intact. A missing reply fails closed with a retry message. Launch profile/map replacement continues to use their existing dirty checks. Merely switching tabs retains editor state.

`military.css` is embedded in all six documents via `tools/sync-workspace-ui.js`: launcher, map editor, side setups, air, ground and campaign editors. The theme uses graphite/sand/olive, a subtle map grid, consistent controls, headings, focus outlines, panel edges and status colours. Semantic side colours remain distinguishable. Embedded operation headers are compact so form fields remain reachable in smaller windows. No external fonts or images are needed. Reduced-motion preference disables button transitions.
